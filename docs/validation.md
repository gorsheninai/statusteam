## Сравнение внешнего вида

Исходная и новая сборки открыты одним Chromium при одинаковых настройках.
Для устойчивого сравнения отключены движения, видео оставлено на постере,
дождались загрузки шрифтов и декодирования всех изображений.

| Ширина | Высота снимка | Различающиеся пиксели |
|---|---|---|
| 360 | 9271 | 2; отличие одного канала на 1 из 255 |
| 390 | 9613 | 2; отличие одного канала на 1 из 255 |
| 768 | 12142 | 4; отличие одного канала на 1 из 255 |
| 900 | 12991 | 0 |
| 1024 | 8622 | 0 |
| 1440 | 9798 | 0 |
| 1920 | 11019 | 0 |

Размеры, положение и выбранные вычисленные стили всех 707–709 элементов страницы
совпадают на каждой ширине. React изменил два автоматически генерируемых `useId`
для скрытых инструкций каруселей; ссылки `aria-describedby` генерируются вместе с ними.
Анимационный переход на мобильном отдельно проходит существующий `mobile-handoff.mjs`.

## Существующие браузерные проверки

Каждый из шести файлов запущен отдельно на исходной и новой сборках: ошибка одного
набора не скрывала остальные результаты. Набор `npm run verify` нельзя считать полностью
успешным: он уже содержит расхождения с текущим сайтом до реорганизации.

| Набор | До | После | Наблюдение |
|---|---|---|---|
| `mobile-handoff.mjs` | PASS | PASS | Мобильный переход и запуск видео |
| `guest-carousel.mjs` | FAIL | FAIL | Проверка рассчитана на одну карусель из 7 фото; сейчас две карусели из 23 и 21 фото, общий селектор кнопки неоднозначен |
| `faq-editorial.mjs` | FAIL | FAIL | Ожидаемые тексты и часть правил не соответствуют текущему FAQ |
| `pulse-title.mjs` | FAIL | FAIL | Ожидаемые фон, состав и высота заголовочного блока отличаются от текущего сайта |
| `stats-podium.mjs` | FAIL | FAIL | Ожидаемые цифры, отступы, сетка и анимация отличаются от текущего сайта |
| `verify.mjs` | FAIL | FAIL | Есть прежние ошибки/расхождения по типографике, контрасту, разделителям, билетному блоку и pin-анимации |

Для четырёх отдельных неуспешных наборов сообщения до/после совпали. В общей проверке
список неуспешных условий сохранился; измерение видимого фокуса изменилось с 10/12
до 12/12, что относится к временному замеру перехода. Ожидания тестов не переписывались
под результат реорганизации, а существующие визуальные проблемы не скрывались.

Оставшиеся CSS-переопределения и `!important` сохранены ради совместимости каскада.
Следующий отдельный этап — актуализация проверок по утверждённому дизайну и исправление
подтверждённых дефектов, затем сокращение переопределений по конкретным блокам.
