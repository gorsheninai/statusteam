# Структура проекта

Проект разделён по блокам страницы. Псевдоним `@/` указывает на `src/`.

| Папка | Ответственность |
|---|---|
| `src/app` | Маршрутизация, метаданные, подключение шрифтов и сборка страницы из блоков |
| `src/sections` | Семь самостоятельных разделов с компонентами и стилями |
| `src/components/layout` | Навигация, подвал, заставка |
| `src/components/ui` | Общие визуальные элементы |
| `src/components/legacy` | Сохранённые, но не подключённые компоненты прежнего варианта |
| `src/features/forms` | Типы и поля форм, сообщения, отправка |
| `src/content` | Контент и настройки без логики отображения |
| `src/motion` | Анимационные контроллеры и их общие стили |
| `src/lib` | Общие вспомогательные функции |
| `src/assets/fonts` | Локальные шрифты и лицензии |
| `src/styles` | Общие правила, токены, адаптивные правила и порядок каскада |
| `assets/originals` | Неизменённые исходные материалы, не публикуются |
| `public/media` | Оптимизированные изображения и видео, публикуются |
| `scripts` | Проверка каталога и путей медиа |
| `tests` | Существующие браузерные проверки |
| `docs` | Инструкции и карта перемещений |

## Направление зависимостей

`app` собирает `sections`; разделы используют общие компоненты, формы, контент и утилиты.
`content` не импортирует React-компоненты. Форма используется билетным блоком, участием и подвалом.
Карусель получает данные фотографий из `content/archive.ts`.

Глобальные CSS-классы, `id`, `data-*` и структура DOM сохранены: на них опираются анимации,
якоря и существующие проверки. Имена компонентов и папок можно менять с обновлением импортов;
изменение классов требует проверки всех обращений из `src/motion/` и `tests/`.

## Сохранённый код

`Guests.tsx`, `Marquee.tsx` и `ShowReel.tsx` находятся в `src/components/legacy/`.
В текущую страницу они не импортируются. Их исходники сохранены для истории проекта;
новые блоки следует создавать в соответствующем разделе, а не добавлять к legacy.

## Исторические пути

Полная карта файлов находится в `file-moves.json`. Старые пути в проектных навыках
`.claude/skills/` являются историческими ссылками; применяются актуальные пути из этой
карты и правила `CLAUDE.md`. В частности, оригиналы больше не хранятся в корне.
