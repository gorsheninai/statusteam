# Стили

Единственная точка подключения — `src/styles/index.css`, импортируемая из `src/app/layout.tsx`.
Порядок импортов сохраняет действовавший каскад сайта.

- `tokens.css` — цвета, шрифтовые роли, размеры и отступы.
- `base.css`, `primitives.css` — базовые элементы и общие компоненты.
- CSS рядом с разделом — его базовая композиция, типографика, mobile/desktop и отдельные элементы.
- `src/components/layout/*.css` — шапка, подвал и заставка.
- `src/features/forms/styles.css` — формы.
- `src/motion/styles/` — визуальные правила анимаций и переходов.
- `responsive.css`, `editorial.css`, `desktop.css`, `rhythm.css` — общие правила нескольких разделов.

Большой `globals.css` разделён по уже существовавшим границам блоков. Три последовательных
файла STATUS TEAM объединены в `sections/status-team/composition.css`. Пустой
`editorial-typography.css` и его импорт удалены. Остальные слои получили смысловые имена.

## Правила изменения

1. Ищите правило по селектору в папке раздела и общих стилях.
2. Редактируйте существующий ответственный файл. Не создавайте `final`, `fixes`,
   `polish-2` или новый глобальный файл ради одного переопределения.
3. Сохраняйте общие переменные в `tokens.css`, повторяющиеся элементы — в `primitives.css`.
4. После изменения проверяйте все ширины, к которым относится правило, и анимации.

При реорганизации декларации и `!important` сохранены. Массовая отмена переопределений
изменит специфичность и дизайн; дальнейшее сокращение выполняется для конкретного блока
с отдельным визуальным сравнением. Раскладка по папкам не маскирует эту оставшуюся сложность.
