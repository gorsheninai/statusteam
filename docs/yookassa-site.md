# Сайт для модерации ЮKassa

Официальные требования: https://yookassa.ru/docs/support/payments/onboarding/arrangement

## Подготовленная витрина

- Главная: кнопка «Купить билет» ведёт к `#tickets`.
- Один товар: билет на шоу «Пульс Континента», 10 000 ₽ за билет.
- Всего 100 билетов, без выбора мест. Это общий тираж, не счётчик оставшихся мест.
- 30 ноября 2026; LOTTE HOTEL MOSCOW, Москва, Новинский бульвар, 8, стр. 2.
- Сбор гостей 18:30, начало 20:00, московское время.
- Возрастное ограничение 18+ сохранено из действующего FAQ.
- Покупка одного билета за заказ; имя и фамилия, e-mail и телефон покупателя.
  Выбор количества и общий тираж в интерфейсе не показываются. Цена — в итоге и кнопке оплаты.
- Только обязательный чек-бокс условий покупки и возврата. Информация о данных
  покупателей и Политика доступны ссылками; подписки и рекламных чек-боксов нет.
- Электронный QR-билет отправляется на e-mail в течение часа после успешной оплаты,
  доставка бесплатная; кассовый чек — на e-mail заказа. Эти условия подтверждены
  заказчиком для будущего запуска, сервисы пока не реализованы.
- Страница `/contacts/`: продавец ООО «СТАТУС», полное название, ИНН, КПП, ОГРН,
  юридический адрес, два телефона и e-mail из предоставленных юридических документов.
- Ссылка на реквизиты доступна в общем подвале всех страниц и в карточке билета.

Для анкеты ЮKassa после успешной выкладки:

| Поле | Значение |
| --- | --- |
| Адрес сайта | https://statusteam-official.ru/ |
| Ссылка на реквизиты | https://statusteam-official.ru/contacts/ |

## До передачи на модерацию

Сайт ещё не объявлен готовым к модерации: страницы правовых документов остаются
заглушками до получения окончательных текстов. Потребуются опубликованное
Пользовательское соглашение с разделом 7, Политика и сведения о данных покупателей.
В юридических черновиках остаются название прошлого шоу, даты и сведения о сервисах.
Сведения о мероприятии и обещанный срок отправки должны совпадать с окончательными
документами. Отдельная оферта не создаётся.

Выкладка на домен ранее завершалась ошибкой FTPS `500 This security scheme is not
implemented`. Подготовка в GitHub не доказывает появление страницы на домене;
после исправления деплоя нужно открыть главную, `/contacts/` и ссылки на документы
без входа, проверить мобильную версию и доступность по HTTPS.

## Оплата не включена

Заказчик выбрал подготовку сайта для модерации. `CHECKOUT_ENABLED` в
`src/content/ticket.ts` равен false; форма не делает сетевых запросов, не сохраняет
введённые данные и не имитирует создание заказа, платёж, выдачу билета или чека.
Само изменение этого флага не подключает оплату: обработчик формы ещё нужно
реализовать после выбора и настройки серверных сервисов.

Перед запуском нужны серверное создание и хранение заказа, проверка остатка и цены
на сервере, идемпотентное создание платежа ЮKassa, проверка подтверждённого платежа,
генерация уникальных билетов, отправка писем и фискальных чеков, возвраты.
Секретные ключи нельзя размещать в клиентском коде или NEXT_PUBLIC-переменных.

## Проверка

`npm run typecheck`, `npm run build`, `npm run verify:media`,
`node --test tests/consents.mjs tests/cookie-choice.mjs tests/ticket-order.mjs`.
Статический HTML проверяется на отсутствие предзаказа, правильность товара,
покупательских полей, одного чек-бокса и полного набора реквизитов.
Сценарии `tests/verify.mjs` обновлены под покупку. Браузерный прогон не выполнен:
управляемое preview передаёт несовместимые с Next.js параметры --host/--strictPort.
