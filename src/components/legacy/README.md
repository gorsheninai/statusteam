# Сохранённые компоненты

Эти три компонента не импортируются текущей страницей. Они перемещены без удаления
реализации; актуальные блоки находятся в `src/sections/`.

- `Guests.tsx` — прежняя стена гостей.
- `Marquee.tsx` — прежняя бегущая строка логотипов.
- `ShowReel.tsx` — прежний видеоплеер; активный — `sections/status-team/ImpactVideo.tsx`.
